# قاعدة بيانات منصة المتاجر (Supabase)

قاعدة واحدة لكل المتاجر. كل صف فيه `store_id`، وقواعد Row Level Security بتضمن إن فريق كل متجر ما يشوفش غير متجره.

## الملفات (بالترتيب)

| الملف | بيعمل إيه |
|---|---|
| `01_setup.sql` | كل الجداول والفهارس |
| `02_security_and_logic.sql` | الصلاحيات (RLS)، والتريجرز (المخزون، سجل الحالات)، ودوال الداشبورد |
| `03_seed_yasmeen.sql` | أول متجر: الياسمين، بمناطقه وسياساته وإعدادات البوت |
| `04_bot.sql` | مستخدم n8n (`n8n_bot`) ودوال البوت، ومنها مزامنة المنتجات من الموقع |

كل الملفات تقدري تشغليها أكتر من مرة من غير ما تكرر حاجة.

## الخطوات

1. **اعملي المشروع:** من supabase.com اعملي حساب ومشروع جديد.
   - Region: **Central EU (Frankfurt)**.
   - احفظي Database Password في مكان آمن.
2. **اعملي المستخدمين:** من Authentication ← Users ← Add user ← Create new user، اعملي:
   - حسابك إنتي (أدمن المنصة).
   - حساب صاحب متجر الياسمين، لو جاهز.
3. **شغّلي الملفات:** من SQL Editor ← New query، الصقي كل ملف واضغطي Run، بالترتيب:
   1. `01_setup.sql`
   2. `02_security_and_logic.sql`
   3. `03_seed_yasmeen.sql`، بعد ما تغيّري `YOUR_EMAIL@example.com` لإيميلك، و`OWNER_EMAIL@example.com` لإيميل صاحب المتجر.
   4. `04_bot.sql`. وبعده شغّلي السطر ده لوحده بباسورد طويلة من اختيارك (احفظيها، هتحطيها في n8n بس):
      ```sql
      alter role n8n_bot with password 'باسورد-طويلة-عشوائية';
      ```
4. **اقفلي التسجيل العام:** من Authentication ← Sign In / Providers، اقفلي **Allow new users to sign up**. المتاجر والحسابات بتتعمل من عندك إنتي، مش أي حد يسجّل.
5. **المفاتيح:** من Project Settings ← API Keys:
   - **Project URL** و**publishable / anon key**: دول للداشبورد، وابعتيهم ليا عادي.
   - **secret / service_role key**: مش محتاجينه خالص. البوت مش بيستخدمه، فما تحطيهوش في أي حتة وما تبعتيهوش في الشات.
6. **ربط n8n:** في n8n اعملي Credential جديد من نوع **Postgres** باسم `Supabase (n8n_bot)`:
   - من Supabase اضغطي **Connect** فوق، واختاري **Session pooler**، وخدي منه الـ Host والـ Port.
   - Database: `postgres`
   - User: `n8n_bot.` وبعدها الـ project ref، مثلًا `n8n_bot.abcdefghijkl` (الـ ref هو الجزء اللي في لينك المشروع).
   - Password: الباسورد اللي حطيتيها في خطوة `04_bot.sql`.
   - SSL: Require.
   وبعدين اختاري الـ Credential ده في الـ 3 nodes: *Begin Turn* و*Submit Order* و*Finish Turn*.

## مين يشوف إيه

| الجدول | الموظف | صاحب المتجر | الأدمن (إنتي) | البوت (n8n) |
|---|---|---|---|---|
| الطلبات، المحادثات، الرسائل، الزباين | قراءة وتعديل | + حذف | كل المتاجر | من خلال دوال `bot.*` بس |
| المنتجات | قراءة + «نفدت الكمية» | + إضافة وحذف | كل المتاجر | مزامنة من الموقع كل 30 دقيقة (من غير ما يلمس اختيارات الفريق) |
| حركة المخزون | قراءة + توريد/جرد/بيع يدوي | نفس الموظف | كل المتاجر | ممنوع |
| الإعدادات، المناطق، السياسات، القنوات | قراءة | تعديل | كل المتاجر | قراءة (من خلال `bot.begin_turn`) |
| الاشتراك (الحالة، التجديد) | قراءة | قراءة | تعديل | ممنوع (بس بيسكت لو المتجر متوقف) |
| تكلفة الذكاء الاصطناعي | ممنوع | ممنوع | قراءة | لسه مش بيكتب |
| الزوّار من غير تسجيل دخول | ممنوع على كل الجداول | | | |

## اللي بيحصل لوحده

- **المخزون:** لو المتجر شغّال بوضع `quantity`:
  - الكمية بتنقص لما الموظف يغيّر الطلب لـ«مؤكد»، مش لما البوت يسجّله.
  - الكمية بترجع لو الطلب اتلغى، ولو الطلب اتنقل لـ«اتشحن» ما بتنقصش تاني.
  - لما الكمية توصل صفر، الصنف بيتعلّم «خلص» والبوت يبطّل يعرضه.
  - الأصناف اللي لسه ما اتعدّتش (`stock_qty` فاضي) ما بتتأثرش.
- **سجل الحالات:** كل تغيير حالة بيتسجّل فيه مين غيّر وإمتى.
- **خطوات الطلب:** الموظف ما بيقدرش ينقل الطلب لحالة مش منطقية (مثلًا من «ملغي» لـ«اتسلّم»).
- **صاحب المتجر:** لازم يفضل للمتجر صاحب واحد على الأقل، فما ينفعش يتشال آخر صاحب.
- **الطلب المكرر:** `idempotency_key` بيمنع إن نفس الطلب يتسجّل مرتين.
- **إعدادات المتجر الجديد:** أي متجر جديد بتتعمل له إعدادات السياسات والبوت تلقائي.
- **التحديث اللحظي:** الطلبات والمحادثات بتظهر في الداشبورد أول ما تيجي (Realtime).
- **البوت يسكت:** لو موظف ضغط «أنا برد» على محادثة، أو البوت مقفول من الإعدادات، أو المتجر متوقف، البوت ما بيردش، بس رسالة الزبون بتتحفظ وبتظهر في المحادثات.

## دوال الداشبورد

| الدالة | لمين | بتعمل إيه |
|---|---|---|
| `my_stores()` | الكل | المتاجر اللي المستخدم يقدر يدخلها، ودوره فيها |
| `store_stats(store_id, from, to)` | أعضاء المتجر | أرقام صفحة الإحصائيات |
| `store_team(store_id)` | أعضاء المتجر | الفريق بإيميلاتهم |
| `add_store_member(store_id, email, role)` | صاحب المتجر | يضيف موظف عنده حساب |
| `queue_staff_reply(conversation_id, text)` | أعضاء المتجر | يحفظ رد الموظف على عميل ماسنجر أو إنستغرام (لو آخر رسالة من العميل خلال 24 ساعة) ويوقف البوت، وبعدها n8n يبعته |
| `admin_create_store(name, slug, prefix, owner_email)` | الأدمن | متجر جديد بتجربة 14 يوم |
| `admin_store_overview()` | الأدمن | صف لكل متجر: الحالة، الطلبات، المحادثات، تكلفة الذكاء الاصطناعي آخر 30 يوم |

## متجر جديد بعد الياسمين

```sql
select admin_create_store('اسم المتجر', 'store-slug', 'AB', 'owner@email.com');
```

بعدها صاحب المتجر يكمّل من الداشبورد: المناطق، والسياسات، وإعدادات البوت، والقنوات.
